# Student guide

DOC-27 · Version 0.1 · proposed · Owner: Student services lead

**Purpose and scope** — Plan a valid bundle, register, recover an uncertain result and respond to offers.

**Audience** — Students and help desk.

**Dependencies** — [Academic rule evaluation](06-academic-rule-engine.md), [Enrollment and waitlists](09-enrollment-waitlist.md), [Next.js frontend and user experience](14-nextjs-frontend-ux.md).

## Build and confirm a course selection
In the proposed student portal, choose the term and open the offering list. Read the course credit value and select a section. Pick one compatible option for each required component. A lab and lecture can each need a seat even when the course awards credit once. Use the weekly table to review dates, rooms and overlaps.
Choose Preview. Read the reasons alongside any missing prerequisite, credit limit or time conflict. If a completion is missing, ask the academic office to review the record. If an exception is allowed, submit supporting evidence through the designated office. A preview does not hold seats. Choose Confirm once and retain the request reference. A receipt with committed status is the confirmation.

## When the result is uncertain
If the connection drops, reopen Request status after signing in with the same identity. A finished receipt confirms the change. A recorded refusal gives the reason and recovery action. While pending, retain the original request reference. If no result appears, resubmit the same intent using the existing key through the recovery action. Check the current schedule before starting a different request.
To swap, select the existing course and the complete replacement. If the replacement fails, the old course remains. To drop, review corequisites and the credit minimum if the registration is finalized. Finalize after the intended schedule is complete.
## Waitlist offer
Join a queue for a specific complete bundle. An offer shows its expiry in the institution’s timezone. Accept before expiry and wait for the enrollment receipt. Declining or letting the offer expire releases the held seats. If eligibility has changed, review the reason and contact the office with the request ID. Queue rank may change according to the institution’s approved priority policy.
